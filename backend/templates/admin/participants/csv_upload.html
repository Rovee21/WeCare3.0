Expected fields (any column names work, in any order)

It's completely fine if your columns aren't in the same order as the template — each one is matched by its name, not its position.

  • Email address
  • First name / Last name
  • Gender, Age
  • Care relationship (spouse / children / relative)
  • Study cohort (intervention / control)
  • Burden/stress group (high / low)
  • ADRD stage (mild / moderate / severe)
  • Cohort / recruitment wave (e.g., 1, 2, 3...)
